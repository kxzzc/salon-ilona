# Простір краси «Ілона» — сайт салону краси

Односторінковий статичний сайт салону краси «Ілона» у Волочиську (Україна).
Салон працює як простір, де незалежні майстри орендують робочі місця, тому
запис іде напряму до кожного майстра — у Telegram, Viber або телефоном.

Сайт зроблений без фреймворків, збірки та npm: один файл `index.html`
з внутрішнім CSS і мінімальним JavaScript. Готовий до GitHub Pages.

## Структура

```
salon-ilona/
├── index.html   ← весь сайт: розмітка, стилі, скрипт
└── README.md    ← ця інструкція
```

## Що де редагувати

| Що змінити | Де |
| --- | --- |
| Телефон | Пошукайте `[ТЕЛЕФОН]` та `tel:+380XXXXXXXXX` у секції «Контакти» і в блоці оренди |
| Адреса, графік роботи | Секція «Контакти» (плейсхолдери `[АДРЕСА]`, `[ГОДИНИ РОБОТИ]`) — і графік у головному екрані |
| Майстри, послуги, ціни | Масив `masters` у `<script>` внизу `index.html` |
| Посилання на запис | Поле `link` кожного майстра (`https://t.me/нік` або `tel:+380...`) |
| Фото | Плейсхолдери `[ФОТО]`; у TODO-коментарях показано, як замінити на `<img>` |
| Карта | Блок `[КАРТА GOOGLE MAPS]` — коментар із прикладом `<iframe>` |
| Instagram | Кнопка в контактах: `https://www.instagram.com/USERNAME` |
| Акцентний колір | CSS-змінна `--accent` у `:root` на початку `<style>` |

### Як змінити майстра

Усі картки малюються з одного масиву, тому достатньо відредагувати його:

```js
{
  name: "Олена",
  role: "Майстер манікюру",
  photo: "photo/olena.jpg",       // або "" — тоді буде плейсхолдер [ФОТО]
  services: [
    { name: "Манікюр з покриттям", price: "450" },
    { name: "Нарощування нігтів", price: "900" }
  ],
  link: "https://t.me/olena_nails"
}
```

Щоб додати майстра, скопіюйте один об’єкт `{ ... }` і змініть дані.
Ціна `"___"` показується як «від ___ грн» — замініть на число.

### Фото

1. Створіть поруч із `index.html` папку `photo/` і покладіть туди зображення.
2. У масиві майстрів вкажіть `photo: "photo/ім’я.jpg"` — картка покаже кругле фото.
3. Для головного екрана замініть `<div class="photo-slot">[ФОТО САЛОНУ]</div>`
   на `<img src="photo/salon.jpg" alt="Салон «Ілона» у Волочиську">`
   (стилі для зображення в арці вже є).

### Карта

У Google Maps натисніть «Поділитися» → «Вставити карту», скопіюйте `<iframe>`
і вставте його замість блоку `.map-placeholder` (приклад є в коментарі в коді).

## Локальний перегляд

Просто відкрийте `index.html` у браузері — сайт працює без сервера.
Для перевірки на телефоні в тій самій Wi-Fi мережі можна запустити
локальний сервер, наприклад:

```powershell
python -m http.server 8000
```

і відкрити `http://<IP-комп'ютера>:8000/index.html` на телефоні.

## Публікація на GitHub Pages

Сайт опубліковано:

```
https://salon-ilona.github.io/
```

Репозиторій: https://github.com/salon-ilona/salon-ilona.github.io

Сайт живе в безкоштовній організації `salon-ilona`, тому адреса не містить
особистого ніка. Параметри публікації: публічний репозиторій
`salon-ilona.github.io`, гілка `main`, папка `/ (root)`,
Source: **Deploy from a branch**.

Щоб оновити сайт після редагування `index.html`:

```powershell
git add index.html
git commit -m "Оновлення сайту"
git push
```

GitHub Pages перебудує сторінку автоматично за 1–2 хвилини.

`og:url` у `<head>` уже вказує на опубліковану адресу.

## Плейсхолдери, які треба заповнити

- `[ГОДИНИ РОБОТИ]` — у головному екрані та в контактах
- `[АДРЕСА]` — точна адреса салону
- `[ТЕЛЕФОН]` і `tel:+380XXXXXXXXX` — телефон салону (контакти + оренда)
- `[Ім’я майстра]` — 4 імені
- `___` — ціни 8 послуг
- `USERNAME_1…4` — Telegram-посилання майстрів
- `USERNAME` — Instagram салону
- `[ФОТО САЛОНУ]`, `[ФОТО]` — фотографії
- `[КАРТА GOOGLE MAPS]` — iframe Google Maps
